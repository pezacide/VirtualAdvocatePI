# Doctor Questions Prompt Template

## Draft task type

DOCTOR_QUESTIONS

## Purpose

Create practical appointment-preparation questions for a doctor, specialist or health provider.

## Instructions

Create questions, not instructions to the doctor.

Do not pressure the doctor to provide a diagnosis or opinion.

Do not ask the doctor to make a DVA decision.

Focus on diagnosis or clinical picture, symptoms, treatment, medication, side effects, functional impact, stability, flare-ups, change over time, referrals, investigations and documents to request.

Use plain Australian English.

Group questions under simple headings.

## Required structure

Preparation-only heading.

Questions about current clinical picture.

Questions about treatment and medication.

Questions about functional impact.

Questions about change over time, if relevant.

Questions about documents or referrals.

Review note.

## Source handling

Include source references only from supplied citation markers.
