# Worsening Summary Prompt Template

## Draft task type

WORSENING_SUMMARY

## Purpose

Create a cautious, plain-English worsening summary draft from active workspace data and approved source references.

## Instructions

Use only supplied facts.

Explain what the veteran says has changed over time.

Include when the change was noticed if supplied.

Include current symptoms, functional impact, treatment changes, medication changes or specialist involvement if supplied.

Include previous DVA acceptance, PI or DCP history only if supplied.

Use careful wording such as 'I have noticed', 'I experience', or 'this may need supporting evidence'.

Do not assert formal worsening unless the user supplied supporting details.

Do not calculate impairment change.

Do not estimate compensation.

Do not predict a DVA outcome.

## Required structure

Preparation-only heading.

Condition and previous context.

What has changed.

Current impact.

Treatment or evidence changes.

Evidence already organised.

Evidence gaps or doctor questions.

Review note.

## Source handling

Include a short Source references section using the supplied citation markers.

Only cite supplied source markers.
