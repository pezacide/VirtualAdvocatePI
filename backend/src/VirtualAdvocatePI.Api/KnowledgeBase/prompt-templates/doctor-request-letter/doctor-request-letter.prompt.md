# Doctor Request Letter Prompt Template

## Draft task type

DOCTOR_REQUEST_LETTER

## Purpose

Create a polite preparation letter the veteran can review before asking a doctor or provider for information.

## Instructions

Use respectful and non-pressuring language.

Explain that the veteran is organising claim-related information.

Identify the condition or issue if supplied.

Ask for a current clinical summary only where appropriate.

Ask for symptoms, treatment, medication and functional impact information only where appropriate.

Ask for copies of relevant reports, referrals, summaries or records where appropriate.

Do not tell the doctor what opinion to give.

Do not ask the doctor to make a DVA decision.

Do not state that the letter guarantees any outcome.

## Required structure

Preparation-only heading.

Opening request.

Condition or issue.

Information being requested.

Optional document request.

Polite closing.

Review note.

## Source handling

Include source references only from supplied citation markers if relevant.
