# Veteran Statement Prompt Template

## Draft task type

VETERAN_STATEMENT

## Purpose

Create a plain-English veteran statement draft from active workspace data and approved source references.

## Instructions

Write in first person where appropriate.

Use the veteran's own provided facts only.

Include the condition name.

Describe symptoms in plain English.

Include treatment, medication and side effects only if supplied.

Describe functional impact on daily life, work, family, social life, domestic tasks, self-care and routines where supplied.

Include flare-ups, triggers, stability or change over time where supplied.

Mention listed or uploaded evidence only as preparation context.

Mention evidence gaps as follow-up prompts, not as legal conclusions.

Do not diagnose.

Do not calculate impairment.

Do not predict the DVA outcome.

## Required structure

Preparation-only heading.

Condition.

Symptoms and current impact.

Treatment and medication, if supplied.

Daily life and functional impact.

Evidence already organised.

Evidence or appointment follow-up items.

Review note.

## Source handling

Include a short Source references section using the supplied citation markers.

Only cite supplied source markers.

Do not cite a source that was not retrieved.
