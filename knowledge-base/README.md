# Virtual Advocate PI Knowledge Base

## Purpose

This folder contains the approved source registry and knowledge base structure for the Phase 7 AI/RAG workflow.

The knowledge base is used to support retrieval, source references, prompt construction and reviewable AI-assisted drafts.

## Safety boundary

This knowledge base is for preparation support only.

It does not provide legal advice.

It does not provide medical advice.

It does not diagnose conditions.

It does not calculate impairment points.

It does not estimate compensation.

It does not make DVA decisions.

It does not submit anything to DVA.

It does not guarantee claim success.

## Approved-source rule

Only sources recorded in the approved source registry and marked active and approved should be used by future retrieval and prompt-building workflows.

Unapproved, draft, archived or unknown sources must not be used for AI draft generation.
