# Worsening summary template

## Required structure

Preparation-only heading.

Condition and prior acceptance context if provided.

What has changed over time.

When the change was first noticed, if provided.

Current severity and day-to-day impact.

Treatment changes, medication changes or specialist involvement if provided.

Relevant evidence already listed or uploaded.

Missing evidence or questions to ask a doctor.

Review note reminding the user to check accuracy before use.

## Style

Use careful language such as 'I have noticed', 'I have experienced', or 'I understand this may need to be supported by evidence'.

Do not assert formal worsening unless supported by user-provided information.

Do not calculate impairment change.

Do not predict DVA outcomes.
