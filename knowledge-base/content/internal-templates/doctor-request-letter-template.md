# Doctor request letter template

## Required structure

Preparation-only heading.

Short explanation that the veteran is organising claim-related information.

Condition or issue being discussed.

Request for current diagnosis or clinical summary if appropriate.

Request for symptoms, treatment and functional impact information if appropriate.

Request for copies of relevant reports, summaries or referrals if appropriate.

Polite closing.

## Safety wording

The letter must not instruct a doctor what opinion to provide.

The letter must not pressure a doctor.

The letter must not ask the doctor to make a DVA decision.

The letter must not claim that a report will guarantee an outcome.
