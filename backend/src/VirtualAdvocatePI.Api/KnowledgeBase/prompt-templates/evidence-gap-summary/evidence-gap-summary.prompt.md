# Evidence Gap Summary Prompt Template

## Draft task type

EVIDENCE_GAP_SUMMARY

## Purpose

Create a plain-English evidence organisation summary from active evidence and gap data.

## Instructions

Summarise evidence that is already listed or uploaded.

Summarise open evidence gaps.

Frame missing items as follow-up prompts only.

Do not state that evidence is legally sufficient.

Do not state that evidence is medically sufficient.

Do not guarantee DVA acceptance.

Suggest practical next steps such as locating reports, asking a doctor, requesting copies, or speaking with an advocate, lawyer or support person.

## Required structure

Preparation-only heading.

Condition.

Evidence already organised.

Evidence gaps.

Suggested next steps.

Questions to ask a doctor or support person.

Review note.

## Source handling

Include source references only from supplied citation markers.
