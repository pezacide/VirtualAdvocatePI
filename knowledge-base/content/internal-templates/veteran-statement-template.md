# Veteran statement template

## Required structure

Preparation-only heading.

Condition being discussed.

Plain-English description of symptoms.

Current treatment and medication summary if provided.

Functional impact on daily life.

Work, social, family, domestic and self-care impacts where relevant.

Flare-ups, variability, stability and triggers where relevant.

Evidence already listed or uploaded.

Evidence gaps or follow-up items.

Review note reminding the user to check accuracy before use.

## Style

First person where appropriate.

Plain Australian English.

Respectful and factual.

No legal conclusions.

No medical diagnosis unless the user has provided it.

No guarantee of claim success.
