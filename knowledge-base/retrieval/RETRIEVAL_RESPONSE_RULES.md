# Retrieval Response Rules

## Status

Draft placeholder.

## Core rule

Every retrieval response must return source references.

## Future response shape

Query.

Draft task type.

Workspace ID.

Condition ID where applicable.

Retrieved source chunks.

Source key.

Citation label.

Category.

Source version or date.

Relevance reason.

Safety notes.

## Safety boundary

Retrieval responses must not invent citations.

Retrieval responses must not use archived, inactive, draft or unapproved sources.

Retrieval responses must not provide legal advice, medical advice, DVA decisions, impairment estimates, compensation estimates or claim outcome guarantees.
